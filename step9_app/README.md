# gorkanai — Türkçe Ürün Yorumu Duygu Analizi

Türkçe bir ürün yorumu yazın, model onu **pozitif / nötr / negatif** olarak sınıflandırsın.

Model: [`Urartu65/gorkanai-tr-sentiment`](https://huggingface.co/Urartu65/gorkanai-tr-sentiment) —
`dbmdz/bert-base-turkish-cased`'in ~17k gerçek ürün yorumu üzerinde ince ayarlanmış hali.

Kod ve tüm geliştirme süreci (adım 1'den 14'e, her adımda öğrenilen dersle birlikte):
[github.com/GoGonuldas/gorkanai](https://github.com/GoGonuldas/gorkanai)
